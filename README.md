# US Home Finder — MVP

A static landing-page MVP for a U.S. property research / relocation assistance service.

## Files
- index.html — website
- style.css — design
- script.js — demo form behavior

## Run locally
Open `index.html` in a browser.

For a local server:
- Python: `python -m http.server`
- Then visit `http://localhost:8000`

## Before launch
1. Replace the placeholder brand/name if desired.
2. Connect the form to a real backend/form provider.
3. Add your real contact details and privacy policy.
4. Replace external demo images with licensed/owned assets if appropriate.
5. Confirm the exact services you offer are compliant with the laws of each U.S. state you target.
6. Set up a real payment processor only after your business structure and terms are ready.

The site intentionally describes the service as property research/relocation assistance rather than licensed real-estate brokerage.
